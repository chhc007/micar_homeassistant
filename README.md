# 小米汽车 Home Assistant 集成（免费版）

> 把小米汽车（SU7 系列）接入 Home Assistant：实时查看电量、续航、位置，远程控制空调与车门锁。

![HACS](https://img.shields.io/badge/HACS-自定义仓库-41BDF5.svg)

## 功能

### 实时状态
- 🔋 **电量**（百分比）
- 🛣️ **剩余续航**（km）
- 🌡️ **车内温度**
- 📍 **车辆位置**（GPS 地图追踪）

### 远程控制
- ❄️ **空调**：开关 + 目标温度（16-32°C）
- 🔒 **车门锁**：远程锁车 / 解锁

无 license 限制，配置即用。

## 安装（HACS 自定义仓库）

1. HACS → 右上角三个点 → **自定义存储库**
2. 添加：`https://github.com/chhc007/micar_homeassistant`
3. 类别选择：**集成（Integration）**
4. 点击下载，重启 Home Assistant

## 配置

1. 设置 → 设备与服务 → 添加集成 → 搜索 **小米汽车**
2. 输入小米汽车 App 账号（手机号）与密码
3. 手机收到短信验证码后填入
4. 完成 ✅

> 需要先在小米汽车 App 中绑定车辆。支持 SU7 / SU7 Pro / SU7 Max 等 SU7 系列车型。

- 本集成使用小米汽车官方 App 同款接口（纯 HTTP + 短信验证码登录），不影响车辆质保

# 小米汽车 Home Assistant 集成

> 把小米汽车接入 Home Assistant：实时查看电量、续航、位置，远程控制空调、车门锁、车窗、除霜、寻车与后备箱。

## 功能

### 实时状态
- 🔋 **电量**（百分比）
- 🛣️ **剩余续航**（km）
- 📏 **累计里程**（km）
- ⚙️ **档位**（P / R / N / D）
- 🌡️ **车内温度**
- 📍 **车辆位置**（GPS 地图追踪）
- 🚗 **胎压**
- 🪟 **四车窗状态**（位置百分比）
- 🅿️ **车位号**（v0.2.3 新增）

### 远程控制
- ❄️ **空调**：开关 + 目标温度（16-32°C，0.5°C 步进）
- 🔒 **车门锁**：远程锁车 / 解锁
- 🪟 **车窗控制**：全关 / 通风 / 全开（v0.2.0 新增）
- 🌬️ **空调除霜**：一键开启 / 关闭（v0.2.0 新增）
- 📢 **寻车**：远程闪灯 / 鸣笛（v0.2.0 新增）
- 🚪 **电动后备箱**：远程开启 / 关闭（v0.2.1 新增）
- 🔥 **远程启动**：一键远程启动车辆（v0.2.3 新增）

## 安装（HACS 自定义仓库）

1. HACS → 右上角三个点 → **自定义存储库**
2. 添加：`https://github.com/chhc007/micar_homeassistant`
3. 类别选择：**集成（Integration）**
4. 点击下载，重启 Home Assistant

## 配置

1. 设置 → 设备与服务 → 添加集成 → 搜索 **小米汽车**
2. 输入小米汽车 App 账号（手机号）与密码
3. 填写**设备 ID**（见下方说明与获取教程）
4. 手机收到短信验证码后填入
5. 完成 ✅

> 需要先在小米汽车 App 中绑定车辆。本集成基于小米汽车通用接口开发，目前以 SU7 系列为主要测试车型、支持度最好，其他车型如有兼容问题欢迎反馈。

### 📱 设备 ID（deviceId）说明

- **为什么需要**：小米汽车服务端把登录令牌绑定到设备，**设备 ID 必须与你手机小米汽车 App 完全一致**，否则会登录/续期失败（token 类型/绑定不匹配）。
- **设备 ID 是什么**：就是你手机小米汽车 App 的设备标识（App 内部称 mobileId / deviceId），形如 `YSFTVmttfxS0t_G-`（字母、数字、`-`、`_` 组合）。
- **在哪填**：添加集成时，"设备 ID"输入框（必填）。⚠️ 不要填其他车友的、不要随机编造，填你自己手机的。
- **填错了怎么办**：删除该集成，重新添加时填写正确的设备 ID 即可。

### 🔍 如何获取设备 ID（抓包教程）

> 以下为普通用户的操作指引，全程在手机上完成，不需要电脑。

1. 手机安装抓包工具，如 **ProxyPin**（开源免费，应用商店可下载）；按工具内提示安装并信任 HTTPS 证书（Android 按提示导入证书；iPhone 需在"设置 → 通用 → VPN 与设备管理"信任描述文件，并在"关于本机 → 证书信任设置"中开启完全信任）。
2. 打开抓包工具，开启抓包（部分工具需开启系统 VPN 开关）。
3. 打开**小米汽车 App**，随便操作一下（比如刷新车辆状态、查看车辆信息页）。
4. 回到抓包工具，在记录列表中找域名含 `xiaomiev.com` 的请求，点开任意一条。
5. 查看该请求的 **Cookie** 或 **请求体（Body）**，找到 **`mobileId`** 或 **`deviceId`** 字段，复制它的值。
6. 把这个值填入 Home Assistant 配置页面的"设备 ID"输入框即可（格式如 `YSFTVmttfxS0t_G-`）。
7. 抓包完成后记得关闭抓包工具。

> 💡 若某条请求里没有该字段，多翻几条即可（首次登录/拉取车辆列表等请求基本都有）。不同手机型号的 App 显示位置可能略有差异，认准 `mobileId` / `deviceId` 字段名即可。

# 小米汽车集成（Home Assistant）

> 把小米汽车接入 Home Assistant：实时查看电量、续航、位置，远程控制空调、车门锁、车窗、除霜、寻车与后备箱。

## 功能

### 实时状态
- 🔋 **电量**（百分比）
- 🛣️ **剩余续航**（km）
- 📏 **累计里程**（km）
- ⚙️ **档位**（P / R / N / D）
- 🌡️ **车内温度**
- 📍 **车辆位置**（GPS 地图追踪）
- 🚗 **胎压**
- 🪟 **四车窗状态**（位置百分比）
- 🅿️ **车位号**（v0.2.3 新增）

### 远程控制
- ❄️ **空调**：开关 + 目标温度（16-32°C，0.5°C 步进）
- 🔒 **车门锁**：远程锁车 / 解锁
- 🪟 **车窗控制**：全关 / 通风 / 全开（v0.2.0 新增）
- 🌬️ **空调除霜**：一键开启 / 关闭（v0.2.0 新增）
- 📢 **寻车**：远程闪灯 / 鸣笛（v0.2.0 新增）
- 🚪 **电动后备箱**：远程开启 / 关闭（v0.2.1 新增）
- 🔥 **远程启动**：一键远程启动车辆（v0.2.3 新增）

## 安装（HACS 自定义仓库）

1. HACS → 右上角三个点 → **自定义存储库**
2. 添加：`https://github.com/chhc007/micar_homeassistant`
3. 类别选择：**集成（Integration）**
4. 点击下载，重启 Home Assistant

## 配置（两种登录模式）

添加集成时先选择登录模式：

| | 主账号模式 | 共享账号模式 ✅ 推荐 |
|---|---|---|
| **适用人群** | 特殊场景（无法创建共享账号时） | **绝大多数用户** |
| **设备 ID** | 需抓包获取（必填，麻烦） | **自动生成**（无需填写） |
| **准备步骤** | 手机抓包 1 次（繁琐） | 注册小米账号 + 车主授权 1 次（简单） |
| **账号来源** | 车主自己的小米汽车 App 账号 | 车主授权共享的全新小米账号 |
| **难度** | ⭐⭐（需抓包） | ⭐（纯操作） |

> 💡 **强烈推荐使用共享账号模式**：全程无需抓包，只需注册一个小米账号并让车主在小米汽车 App 里授权一下，3 分钟即可完成。两种模式登录后功能完全一致，**主账号模式没有任何额外优势**，仅在没有其他小米账号可用时才需要选择。

### 通用步骤

1. 设置 → 设备与服务 → 添加集成 → 搜索 **小米汽车**
2. 选择登录模式（主账号 / 共享账号）
3. 输入账号与密码，手机收到短信验证码后填入
4. 账号下有多辆车时，**选择要添加的车辆**
5. 完成 ✅

> 🚗 **一个账号多辆车（v0.2.8）**：登录后会把账号下**全部车辆**列出来供选择——包括你自己的多辆车和他人授权共享给你的车，共享的车会标注「（共享）」。每辆车对应一个独立的配置条目：**想添加多辆车，就重复「添加集成」流程，每次选择不同的车**。每辆车的实体名带车牌后缀（如「电量 我的车」）、设备按车辆区分，互不冲突。

### 🔑 模式一：共享账号模式（推荐，无需抓包）

**原理**：车主把车辆"授权共享"给一个新注册的小米账号，用这个共享账号登录集成即可。设备 ID 由集成自动生成，全程不用抓包。

**第一步：注册全新小米账号**

1. 打开小米官网（www.mi.com）或用任意小米 App（如小米商城）注册一个新账号
2. 用**手机号**注册即可，不需要小米手机、不需要实名
3. 记下这个账号和密码，后面登录集成要用

**第二步：车主授权共享车辆**

1. 车主（你自己或家人）打开**小米汽车 App**，登录主账号
2. 进入 **我的 → 车辆管理 → 授权共享**（不同版本 App 菜单位置略有差异，找"共享"/"授权"入口）
3. 按提示输入共享账号的手机号，完成授权
4. 授权后可先退出主账号，用共享账号登录小米汽车 App 验证一下：能看到车辆信息即授权成功

> 💡 授权共享后，共享账号在 App 里能看到车辆、能远程控制（与主账号权限一致）。如只授权查看、不授权控制，集成仍可查看状态。

**第三步：用共享账号添加集成**

1. Home Assistant → 添加集成 → 小米汽车 → 选择 **共享账号模式**
2. 输入共享账号（手机号）与密码
3. **设备 ID 自动生成，无需填写**
4. 填入短信验证码 → 完成 ✅

### 📱 模式二：主账号模式（车主本人，需抓包）

**原理**：直接用车主自己的小米汽车账号登录，设备 ID 必须与手机小米汽车 App 完全一致（需抓包获取一次）。

> 以下为普通用户的操作指引，全程在手机上完成，不需要电脑。

**获取设备 ID（抓包教程）**：

1. 手机安装抓包工具，如 **ProxyPin**（开源免费，应用商店可下载）；按工具内提示安装并信任 HTTPS 证书（Android 按提示导入证书；iPhone 需在"设置 → 通用 → VPN 与设备管理"信任描述文件，并在"关于本机 → 证书信任设置"中开启完全信任）。
2. 打开抓包工具，开启抓包（部分工具需开启系统 VPN 开关）。
3. 打开**小米汽车 App**，随便操作一下（比如刷新车辆状态、查看车辆信息页）。
4. 回到抓包工具，在记录列表中找域名含 `xiaomiev.com` 的请求，点开任意一条。
5. 查看该请求的 **Cookie** 或 **请求体（Body）**，找到 **`mobileId`** 或 **`deviceId`** 字段，复制它的值。
6. 抓包完成后记得关闭抓包工具。

> 💡 若某条请求里没有该字段，多翻几条即可（首次登录/拉取车辆列表等请求基本都有）。不同手机型号的 App 显示位置可能略有差异，认准 `mobileId` / `deviceId` 字段名即可。

**添加集成**：

1. Home Assistant → 添加集成 → 小米汽车 → 选择 **主账号模式**
2. 输入小米汽车 App 账号（手机号）与密码
3. 填写**设备 ID**（抓包得到的值，形如 `YSFTVmttfxS0t_G-`）——⚠️ 不要填其他车友的、不要随机编造，填你自己手机的
4. 填入短信验证码 → 完成 ✅

> 设备 ID 填错了怎么办：删除该集成，重新添加时填写正确的设备 ID 即可。

## 常见问题

**Q：共享账号模式登录后提示"未找到车辆"？**
A：确认车主已在小米汽车 App 里完成授权共享，并且授权给的就是你登录用的这个账号。

**Q：主账号模式登录失败 / 提示设备 ID 不正确？**
A：设备 ID 必须与你手机小米汽车 App 一致（token 绑定该设备）。重新抓包确认，或改用共享账号模式。

**Q：共享账号能控制车辆吗？**
A：能。授权共享默认包含远程控制权限（空调、门锁、车窗、启动等均可用）。

**Q：一个账号有多辆车，怎么全部加入 Home Assistant？**
A：添加集成登录后，会列出账号下全部车辆（自己的车 + 被授权共享的车），选择一辆完成添加；再次进入「添加集成」选择另一辆即可。每辆车是独立的配置条目，实体名带车牌后缀、设备按车辆区分，互不冲突。

**Q：升级到 v0.2.8 后旧实体还在吗？**
A：旧版本添加的条目不包含车牌字段，其实体保持原样不受影响；如果删除旧条目重新添加（新条目带车牌），实体 unique_id 会按车辆 vid 区分而重建——旧的实体可能残留为「不可用」状态，可在「设置 → 实体」中手动删除，或直接在旧条目上删除集成后重新添加。
